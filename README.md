# Five Seconds to Explain the Glass

A house cat's five-second defence after knocking a glass off the table: the glass insulted the cat's tail, so the cat showed it the floor. One sentence, no apology, no confession — just a cat's own logic, delivered exactly as a cat would say it in the moment.
